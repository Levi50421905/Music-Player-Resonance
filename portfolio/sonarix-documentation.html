Sonarix

Desktop music player lokal · v1.2.3 · Tauri 2 + React · Windows

Sonarix adalah aplikasi desktop untuk mendengarkan musik dari folder lokal. Tanpa streaming wajib, tanpa akun. Library milik kamu, di mesin kamu.

Kenapa dibuat

Player bawaan OS dan app web sering kurang nyaman untuk koleksi pribadi — terutama FLAC, tag berantakan, atau library besar. Sonarix fokus: scan folder, index SQLite, putar dengan kontrol penuh.

Fitur utama

  • Library scan, virtual scroll, filter format & duplikat
  • Gapless, crossfade, replay gain, shuffle/repeat
  • Auto-mix random saat antrian habis (repeat off)
  • Smart mood / radio, EQ preset, dynamic theme dari cover
  • Lirik LRC + fetch online, fullscreen now playing
  • Bookmark posisi, favorit, rating, play history
  • Tray, media keys, mini player, Last.fm (opsional)
  • Backup/restore DB, edit metadata + tulis tag ke file
