Malam-malam Ngulik Player Sendiri: Sonarix

Catatan development — bukan dokumentasi teknis.

Awalnya sederhana banget: “Pengen app musik lokal yang UI-nya nggak bikin ngantuk.” Itu aja. Nggak ada pitch deck. Cuma frustrasi kecil setiap kali buka folder Music dan harus scroll file satu-satu.

Versi awal cuma list + play. Boring, tapi cukup buat ngetes: apakah saya betah pakai ini sendiri? Jawabannya belum — sampai ada library scan, queue, dan player bar yang stabil.

Hal yang paling terasa “wow” bukan fitur fancy. Saat shuffle playlist kecil habis, app lanjut random tanpa saya pilih lagu lagi. Baru kerasa kayak player, bukan file browser. Itu auto-mix di v1.2.3.

Fullscreen sempat cuma satu baris lirik. Cantik di screenshot, useless pas dipakai. Harus self-contained: lirik scroll, volume, shuffle, repeat — karena player bar ketutup overlay.

Duplikat juga klasik: kolom DB ada, UI belum. Baru keliatan setelah badge + filter tab. Bookmark? localStorage. Hilang ganti browser. Malu sendiri, pindah SQLite.

Dependency autostart sempat kehapus pas nambah crate baru. Build error. Lesson: jangan edit Cargo.toml sambil multitask.

Splash screen agak vanity, tapi nutup jeda blank pas load library. Icon Sonarix + animasi ring — identitas visual sebelum React boot.

Milestone bukan fitur paling banyak. Saat buka app pagi-pagi, shuffle album, fullscreen lirik jalan, nggak kepikiran buka app lain. Itu bar-nya.

Sonarix masih jauh dari perfect. Tapi setiap patch kecil rasanya seperti merapikan meja kerja sendiri. Bukan untuk demo. Untuk dipakai.
